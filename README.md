# Reproducibility
Ciencia reproducible: cómo pasar de la teoría a la práctica

A pesar del consenso entre la nueva generación de investigadores y investigadoras sobre la importancia de hacer una ciencia reproducible, siguen habiendo barreras tanto sociales como técnicas para su implementación. En este taller daremos una serie de herramientas fáciles de usar para que hacer ciencia reproducible no tenga un coste técnico significativo, y discutiremos como lidiar con barreras de indole más filosófico.
